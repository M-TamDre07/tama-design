Alur diagnosis

PC hitam atau Windows rusak tidak langsung divonis.

Kalau perangkat tidak menampilkan Windows, diagnosis dimulai dari power/BIOS, storage, dan media boot. SSD eksternal studio dapat dipakai sebagai media kerja/boot terpisah jika kompatibel, tetapi bukan berarti Windows pelanggan bisa dipindahkan begitu saja.

01 · BIOS / Boot Menu

Cek apakah RAM, storage, dan perangkat boot terdeteksi. Pengaturan boot disesuaikan dengan merek perangkat.

02 · Media kerja

Media eksternal dapat digunakan untuk lingkungan diagnosis seperti Windows PE atau installer Linux dan mengakses drive internal jika tidak terenkripsi/terkunci.

03 · Cek SSD/HDD

Gunakan Disk Management, SMART/health tool, dan pengujian dasar. Jika storage menunjukkan tanda gagal, pelanggan diberi opsi mengganti SSD.

04 · Pilihan pelanggan

Jika storage sehat: install ulang bersih atau backup dahulu. Jika storage bermasalah: jangan dipaksa install ulang sebelum media pengganti siap.

Windows PE adalah lingkungan boot untuk diagnosis/deployment. Windows To Go sebagai fitur Windows resmi sudah dihapus sejak Windows 10 versi 2004, jadi jangan mengandalkan “Windows biasa di SSD eksternal” sebagai metode universal.

BIOS & Boot Menu

Referensi tombol umum.

Tombol dapat berbeda menurut model. Jika gagal, gunakan manual resmi produsen.

Acer

BIOS umumnya F2 · Boot Menu F12.

ASUS

BIOS umumnya F2/Del · Boot Menu Esc.

Dell

BIOS F2 · Boot Menu F12.

HP

Startup Menu Esc · BIOS F10 · Boot Device Options F9.

Lenovo / ThinkPad

BIOS F1/F2 tergantung model · Boot Menu F12/Fn+F12.

MSI / Gigabyte / ASRock

BIOS/UEFI umumnya Del atau F2; Boot Menu sering F11/F12/Esc tergantung board.
